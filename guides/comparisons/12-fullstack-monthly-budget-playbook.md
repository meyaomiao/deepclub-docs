## 一、典型个人全栈工作流月度模型配比（按 30 天估算）

### 1. 日常编码 Agent（Claude Code / Cursor / Codex CLI）
- **主力编码模型**：`claude-sonnet-5-5`（¥1/M 输入、¥0.1/M 缓存读、¥5/M 输出）或 `gpt-6.1-sol`（¥0.7/M 输入、¥0.035/M 缓存读、¥3.5/M 输出）
- **假设每月用量**（含较高缓存命中）：
  - 缓存读 `20M Tokens × ¥0.10/M = ¥2.00`
  - 非缓存输入 `3M Tokens × ¥1.00/M = ¥3.00`
  - 输出代码与解释 `2M Tokens × ¥5.00/M = ¥10.00`
  - 复杂架构切换 `claude-opus-5-5` 辅助排查（约 `0.5M` 混合输出 ≈ ¥6.00）
- **编码板块月计：约 ¥21**

### 2. 网页/论文双语阅读与日常问答（沉浸式翻译 + Chatbox / Cherry Studio）
- **选用模型**：`gpt-6-luna`（¥0.12/M 输入、¥0.60/M 输出）+ `gemini-4-hydrogen`（¥0.60/M 输入、¥3.00/M 输出）
- **假设每月翻译/摘要 5M 输入 + 2M 输出（按混用估算）**：
  - 按 `gpt-6-luna` 主力核算：`5 × ¥0.12 + 2 × ¥0.60 = ¥1.80`（即便全走 `gemini-4-hydrogen` 也仅 `5 × ¥0.60 + 2 × ¥3.00 = ¥9.00`）
- **翻译/日常问答月计：约 ¥3 ~ ¥9**

### 3. 博客配图、原型 UI 与表情/海报素材（Images API）
- **选用模型**：`gpt-image-2`（¥0.16 起/张）、`nano-banana-2`（¥0.24/张）、`gemini-3-pro-image`（¥0.30/张）
- **假设每月生成/编辑 40 张图**：
  - 30 张轻量配图/草图（均价 ¥0.20）= ¥6.00
  - 10 张高质商业/产品精修（¥0.30）= ¥3.00
- **生图板块月计：约 ¥9**

### 4. 产品演示或社媒短视频预演（Videos API）
- **选用模型**：`Seedance-2.0-Mini` 预演（¥1.5 起/个）+ `Seedance-2.0-Fast`（¥2.5 起/个）或 `MiniMax-H3`（¥2.0 起/个）
- **假设每月生成 4 条预演 + 2 条成品短视频（按起步规格估算）**：
  - `4 × ¥1.5 + 2 × ¥2.5 ≈ ¥11`
- **视频板块月计：约 ¥11 ~ ¥18**

## 二、汇总对比：按量聚合网关 vs 多平台固定订阅

| 项目 | 固定月度会员制（海外多平台拼凑） | 深云 DeepClub 纯按量估算（中高频个人全栈） |
|---|---|---|
| 多家官网月费（Chat Pro + 编码助手 + 生图/视频站点） | 往往需要 **\$40 ~ \$100+/月**（约 ¥280~¥720，用不完不退） | 编码 + 翻译 + 生图 + 视频合计约 **¥45 ~ ¥60/月** |
| 出差/停更几天时 | 月费照扣不误 | **消耗为 ¥0**，余额永不过期 |
| 协议与支付 | 各家分开绑海外卡 | 一个 Key 覆盖 36 款在售模型，支持信用卡/微信支付/支付宝 |

**三条进一步压低成本的技巧**：
1. 尽量让 **Claude Code / Codex CLI** 保持原生协议路径并避免把当前时间戳插到 System Prompt 开头，最大化吃满 **`cache_read`** 折扣（详见 [Prompt Caching 省钱指南](https://deepclub.net/compare/prompt-caching-guide)）；
2. 高频入口（翻译、PR 初筛、总结）交给 `gpt-6-luna` / `gemini-4-hydrogen` / `gpt-6.1-terra`；
3. 视频和 4K 大图先用低成本档验证构图后再出最终成片（详见 [AI 生图与视频生成 API 汇总](https://deepclub.net/compare/ai-image-video-api-pricing)）。
